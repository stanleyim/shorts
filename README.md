
# YouTube 트렌드 분석기

정치·사회·뉴스·풍자 관련 유튜브 상위 영상의 썸네일, 제목, 조회수를 분석하는 앱.

## 사용법

1. 우측 상단 **API 키 설정** 클릭 → Apify 토큰 입력 (브라우저에 저장됨)
2. 키워드 선택 또는 직접 입력
3. **▶ 분석 시작** 클릭
4. 상위 10개 영상 결과 확인

## GitHub Pages 설정

Settings → Pages → Source: **main branch / root** → Save
